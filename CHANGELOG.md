# Changelog

All notable project milestones are documented here.

## 0.1.0 — 2026-08

Initial public OSS milestone.

Highlights:

- local Tamil, English, and Tanglish audiobook generation;
- Apple-Silicon-focused low-memory runtime;
- long-form audiobook engine and local ListenLeaf browser/CLI experience;
- PDF, TXT, and Markdown import;
- synchronized read-along and local playback features;
- reproducible automated tests and Apple Silicon validation;
- MIT licensing and public contribution/security documentation.

This version label reflects the package version declared in `pyproject.toml`; it does not imply a separate GitHub Release has been published.
